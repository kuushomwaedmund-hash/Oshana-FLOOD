 🌊 FloodX – Oshana Flood Risk Mapping System

FloodX is a web-based GIS application built using **Python, Streamlit, GeoPandas, and Folium** to visualize flood-prone areas and road networks in the Oshana region of Namibia. The system helps users understand flood risks, explore spatial data, and support decision-making for safer movement and planning.
 Project Purpose

The main goal of FloodX is to:
- Visualize flood-prone areas in Oshana
- Display constituencies and road networks
- Support spatial decision-making during flood events
- Provide an interactive and easy-to-use web GIS tool

---

🗺️ Features

- Interactive web map using **Folium**
- Flood risk visualization
- Constituency boundary display (KML support)
- Road network overlay (CSV data)
- Point-based location analysis
- User-friendly interface using **Streamlit**
- Spatial operations using **GeoPandas & Shapely**
